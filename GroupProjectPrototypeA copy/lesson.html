Introduction to Java

Java is a programming language used to build many different types of applications. Before learning the details, it helps to see what a basic Java program looks like.

Your first Java program

The example below prints a short message to the screen.

Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

What is happening here?

The class is named Main. Inside the class is the main method, which is where the program starts. The System.out.println() statement displays text in the console.

Beginner Tip

Java is case-sensitive. For example, String and string are not the same thing.

Common Mistake

Make sure your class name matches the file name. A class named Main should be saved in a file named Main.java.
